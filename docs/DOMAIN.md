# Перенос сайта на домен keremet.edu.kz

Сейчас сайт работает на https://daulet-rama.github.io/keremet-school-website/ (GitHub Pages, автосборка при каждом `git push` в `main`).

## Данные домена (из письма EDU.KZ от 18.08.2022)
- Домен: **keremet.edu.kz**, регистратор EDU.KZ (Domains Service A), организация ТОО «Keremet City».
- DNS-серверы: `ns.softdeco.com` (80.241.32.85), `ns.softdeco.net` (80.241.34.161).
- Регистрация была оформлена **до 18.08.2023**. На 26.09.2026 домен не открывается, скорее всего срок истёк.

## Шаг 1. Продлить домен
Войти в кабинет EDU.KZ (ссылка «Ваша почта и доступ в платформу EDU.KZ» в том письме) или написать на domain@reg.edu.kz и продлить keremet.edu.kz. Без работающего домена в зоне edu.kz критерий № 38 приказа № 114-НҚ даёт максимум 3 балла.

|---|---|---|

| `www.keremet.edu.kz` | CNAME | daulet-rama.github.io |
| (необязательно) `keremet.edu.kz` | AAAA | 2606:50c0:8000::153, 2606:50c0:8001::153, 2606:50c0:8002::153, 2606:50c0:8003::153 |

Проверка: `nslookup keremet.edu.kz` должен вернуть адреса 185.199.x.153. Обновление DNS занимает от нескольких минут до 24–48 часов.

## Шаг 3. Подключить домен в GitHub (только после шага 2!)
Если сделать это раньше, GitHub начнёт перенаправлять github.io-адрес на неработающий домен.
```bash
gh api -X PUT repos/daulet-rama/keremet-school-website/pages -f cname=keremet.edu.kz
# через 10–30 минут, когда GitHub выпустит сертификат:
gh api -X PUT repos/daulet-rama/keremet-school-website/pages -F https_enforced=true
```
Рекомендуется подтвердить домен в настройках аккаунта GitHub (Settings → Pages → Add a verified domain, TXT-запись `_github-pages-challenge-daulet-rama.keremet.edu.kz`), чтобы его нельзя было привязать к чужому репозиторию.

## Важно для аттестации (5 баллов)
- **Хостинг в Казахстане.** Приказ Минпросвещения № 456 (п. 3) требует размещать интернет-ресурс организации образования на серверах в РК. Серверы GitHub Pages находятся за рубежом, поэтому к аттестации лучше разместить папку `dist/` на казахстанском хостинге с PHP (подойдёт любой хостинг с PHP 7.4+; `.htaccess` уже настроен). Тогда в DNS указывается A-запись этого хостинга вместо адресов GitHub. GitHub можно оставить как хранилище исходников, выгрузку `dist/` по FTP можно автоматизировать через GitHub Actions.
- **Формы обратной связи.** На GitHub Pages PHP не работает, поэтому формы предлагают WhatsApp. На хостинге с PHP заработает `api/feedback.php`: в нём нужно указать настоящий адрес почты (`$CONFIG['to']`).
- **HTTPS обязателен.** На GitHub Pages он включается командой выше, на своём хостинге нужен SSL-сертификат (обычно бесплатный Let's Encrypt в панели хостинга).
